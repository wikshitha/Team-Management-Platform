# Project and Team Task Management Platform

A full-stack project and team task management platform developed for managing users, roles, projects, project members, tasks, progress, comments, notifications, and system activity.

## Technology Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- Axios
- React Hook Form

### Backend

- Node.js
- Express.js
- JavaScript
- Prisma ORM

### Database

- PostgreSQL

Currently under development.
